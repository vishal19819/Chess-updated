# Human Engine — Chess (browser)
Open index.html in any browser. No install, no internet needed.

- engine.js: rules, move generator, evaluation, alpha-beta + quiescence search, human-like move choice
- openings.js: opening/defence database (SAN lines) and book logic
- openings-extra.js: extra variations; add yours with addLines("Name","e4 e5 Nf3 ...")
- app.js: board UI, levels, undo, flip
- style.css: look and feel (light/dark)
